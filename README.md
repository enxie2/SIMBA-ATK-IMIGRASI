# Sistem Baru PHP

Aplikasi pengelolaan ATK berbasis PHP/Node.js untuk kebutuhan sistem pengajuan dan pelaporan.

## Fitur utama
- Login dan sesi pengguna
- Pengajuan permintaan ATK
- Persetujuan admin
- Dashboard statistik
- Laporan cetak

## Cara jalankan

```bash
npm install
npm start
```

Buka http://localhost:8000

## Environment
Buat file `.env` sesuai kebutuhan database dan session secret.
